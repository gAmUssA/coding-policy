### Added

- **`rex-team.sh check`: the lead runs the checks itself** (ADR 0017). A worker's `done` proves it stopped, never that its work is right; following andrebrov/agent-factory-lab experiment 10's validity rules ("never on another agent's word"), the lead now runs commands it chose, one `--run` each, in the developer's worktree after the `candidate` gate. Nothing is read from the worker's report. The command refuses with `check_mismatch` unless the writer's branch tip and the worktree `HEAD` are the candidate, and with `check_dirty` when the worktree has uncommitted or untracked changes, before running anything; both clean-tree reads list every untracked file whatever `status.showUntrackedFiles` is set to. Each command runs with `bash -c`, no stdin and a per-command timeout (default 1800 s) that kills its whole process group, its combined output written to `$REX_TEAM_HOME/<task>/checks/<role>-<k>/<i>.log`; stdout carries the log path, never the output. Exit 0 is `pass`, exit 1 `fail`, and any other exit, a timeout, a signal, exit 126 or 127 (reported as that exit status alone, since the command may have run before exiting with it), or a run that moved `HEAD` or left the tree dirty is `invalid`; a run that changed the worktree stops the remaining runs, which are reported as not run. The overall verdict is `invalid` over `fail` over `pass`, and the command exits 0 whenever its runs were classified. The latest check is recorded on the worker and shown by `status`, and the tab reads `· #<n> checks pass|fail|invalid`. Covered in `skills/rex-teamlead/tests/test_team.py` with real `git` and real `bash -c` commands: pass, fail, exit 2, 126, 127, a signal, a timeout, a command that commits, a command that leaves a file, each refusal in both directions, and the recorded state, plus one run through `python -m rexlead`.

### Changed

- **`skills/rex-teamlead` gates the reviewer on the lead's check.** New Step 8 runs `check` with the commands picked at Step 1: `pass` spawns the reviewer, `fail` sends the developer one correction brief with the log paths, and `invalid` goes to the operator and never enters the fix loop as a code defect. The later steps are renumbered. The reviewer brief names the passed checks, and the reviewer need not rerun the full suite. The Step 6 routing list and the Step 13 blocking-findings bullet are split into atomic bullets, folding in PR #84's last advisories.
- **The Rex team state record is `schema_version` 2.** It adds the optional worker `check` (`candidate`, `verdict`, `checked_at`). The owner upgrades a version-1 record on read and rewrites it; `skills/rex-teamlead/state-schema.md` documents the version handling.
