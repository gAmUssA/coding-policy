### Changed

- **The version is assigned on merge from changelog fragments** (ADR 0003). Every PR that changed shipped content bumped both manifests and wrote the `## <version> — <date>` CHANGELOG heading, and `.github/workflows/publish.yml` published that version as-is. Two such PRs always conflicted, so Herdr rounds that open several PRs at once had to merge them one at a time, rebasing and re-bumping each. A PR now adds `changelog.d/<name>.md` with `bump: patch|minor|major` front matter and its `### <Section>` entries (`changelog.d/README.md`). It never edits a manifest `version` or adds a version heading. `scripts/check-changelog-fragment.sh` replaces `scripts/check-version-bump.sh` as the PR gate in the renamed `changelog-fragment` job. That job diffs the PR from its merge base and no longer reads the registry. On push to `main`, the publish job checks out the current tip. `scripts/assemble-release.sh` takes the highest of the registry and both manifests, bumps it by the highest pending level, writes both manifests and a CHANGELOG entry with sections merged by name, and deletes the fragments. `scripts/push-release.sh` commits `chore(release): <version>` as `github-actions[bot]` and pushes, rebasing once if a merge landed meanwhile. The job then publishes only when the manifest is ahead of the registry, so a merge with no fragment publishes nothing and re-running a failed publish ships the committed version. `rules/context-artifacts.md` Versioning and CHANGELOG states the new contract. `rules/ci-safety.md` Protected Branches gains the narrow exception for the workflow's release commit. The release skill's Steps 1, 3 and 7 run the fragment gate, add a fragment instead of a bump in repos that assemble on merge (other publishing repos still bump by hand), and report a merge without fragments as no publication. Each guard was shown failing with its check removed: the manifest-version, missing-fragment and version-heading checks in the gate, validation before writing in the assembler, and the rebase retry in the push script.
