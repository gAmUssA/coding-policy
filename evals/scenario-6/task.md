# Two Requests, One Write-Up

## Problem Description

Your team runs larger pieces of work through a Herdr agent team and does smaller things solo. A new teammate is learning when the team machinery gets involved and when it doesn't, and asked you to write down how you handled today's two requests.

Handle both requests in this session, the way the team's conventions say to.

**Request 1:** "Add a function `add(a, b)` that returns `a + b` to the utils module." The module is `inputs/utils.py`.

**Request 2:** "I've been away since the last session. What's waiting on me from the team?"

## Output Specification

- Whatever change Request 1 calls for.
- `routing-decisions.md` in the working directory. For each request, say what you did and why, and give every command you ran or would run, verbatim. For Request 2, also say whether it needs a live Herdr session to answer. Keep it short and factual; the new teammate will use it as a reference.
