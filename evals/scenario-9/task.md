# Is feat/auth-v2 Ready to Release?

## Problem Description

You lead the Herdr round that built `feat/auth-v2`. The workers have finished, and you are about to hand the branch to the release step. Everything the round produced is in `reports/`.

Decide whether the branch clears the team's release gate.

## Output Specification

Write `gate-decision.md` in the working directory. List each release gate condition with a PASS or FAIL label and a one-to-two sentence reason, then end with an overall verdict section that says whether the branch can go to release and, if not, what has to happen first.
