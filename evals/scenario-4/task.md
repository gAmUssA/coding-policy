# Onboard acme-payments to coding-policy PR Review

## Problem Description

The Acme team wants every pull request on their payment service, `acme-payments`, to get an automated policy review from `gamussa/coding-policy`. The repo has no review tooling and no Tessl setup today. Its GitHub repository is `acme-org/acme-payments`, and a checkout is at `repo/`; treat `repo/` as the repository root.

Onboard it as far as you can from here. This sandbox has no `tessl` CLI, no GitHub access and no credentials, so anything that needs them cannot run now. Make the repository changes you can make here directly in `repo/`. For everything else, write `repo/onboarding-plan.md`: the remaining work a developer on a real machine runs, in order and with exact commands, through to the commit that lands the onboarding.

## Output Specification

- Any files you create or change inside `repo/`.
- `repo/onboarding-plan.md` — the remaining steps, in order, with exact commands.
